# Social Media Archive

This folder holds the removed NXUS social/event app code so the live app can stay focused on the coming-soon page.

The live entry points left under `src/` are:

- `src/App.jsx`
- `src/main.jsx`
- `src/pages/ComingSoon.jsx`
- `src/components/SocialLinks.jsx`

Some shared brand assets, such as the NXUS logo and app icons, remain in `public/` because the coming-soon page and site metadata still use them.
