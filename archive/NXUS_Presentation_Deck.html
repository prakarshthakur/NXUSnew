Innovation Strategy 2026

NXUS

eBay for Fun — Fun for Everyone.

Founder: Prakarsh Thakur

Ecosystem: NXUS Radar & Redacta

The Problem

University life is loud, but finding "fun" is quiet. Events are hidden in group chats, buried in formal calendars, or lost in noise.

Hard to Find

Low-intent discovery models. Users have to "search" for fun instead of it finding them.

Hard to Host

Barriers to entry for small-scale student events and casual kickbacks.

The Solution

A gamified experience-marketplace that prioritizes Discovery and Simplicity.

Radar (Swipe)

Tinder-style interface for events. High-velocity discovery matching users to experiences.

Liquid Trust

Verified university ecosystem. Safe, exclusive, and hyper-local.

Ecosystem

NXUS Radar

Social Experience discovery.

  • Real-time Feed
  • Hosting Mechanic
  • PWA First Logic

Redacta

AI-Powered Privacy Suite.

  • Instant PII Obfuscation
  • Secure PDF/Doc Analysis
  • privacy-centric UX

Technology

Built for scale and cross-platform flexibility.

  • Frontend: Vanilla JS / CSS (Liquid Glass System)
  • Backend: Firebase Realtime Auth & Sync
  • Wrapper: Capacitor for Web, iOS, Android parity
  • Analytics: GA4 event-driven tracking

Roadmap

Q1: Core Radar UI & Swipe Engine (Complete)

Q2: Firebase Integration & Redacta Alpha

Q3: University Email Verification (.edu)

Q4: "Fun Tokens" - Gamified Monetization

Let's build the future of fun.

NXUS is more than an app; it's the layer of discovery for the next generation.
